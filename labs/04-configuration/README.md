# Lab 04 — configuration and secrets

Inspect the ConfigMap volume, update the HTML, and determine when the running application observes the new file.

Compare environment variables, mounted files, immutable/versioned configuration and rollout annotations.

Security scenario: a Secret manifest was committed. Rotate the real credential first, assess exposure, remove current use, add scanning, and coordinate history cleanup only as an additional control.

Never place a real secret in this repository or lab.
